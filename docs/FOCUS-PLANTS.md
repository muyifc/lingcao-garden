# 灵植与专注时间设计 v1

日期：2026-11-19。用户目标：玩家按收获时间选择自己的专注时长，药园兼作温和的计时器。

## 使用规则

1. 播种条按时间从短到长排列，显示“时长 · 灵植名 · 库存”；十二档从初始境界即可选，购买仍需灵石。
2. 默认开启“专注种植”：一次点空地就开始一株计时；缺种时沿用原价自动购买。切换所选灵植不改变已经种下的计时。
3. 专注株只按墙上时钟自然生长；灵雨跳过它，催熟拒绝且不收费。灵肥只加产量，不改时长。关闭专注种植后，新种的草仍可按原玩法加速。
4. 多块地可以分别计时，不设置唯一专注任务，不锁住其他应用，也不推断玩家是否真的保持注意力。
5. 离线继续计时；成熟后停留在可收状态，迟到不枯萎、不扣奖励。有聚灵阵时到期收获会进入药篓和园志，不自动重种。
6. 到期通过当前倒计时、可收标签与灵珠角标反馈。本轮没有系统通知、声音、专注统计或中断惩罚；自动收获后不保留可收角标，结果见药篓和园志。
7. 8/12/24 小时用于长任务、等待与生活节奏，不表示建议持续不休息工作。

## 存档兼容

- 状态升为版本 2；新种植的地块存 `growMs` 和 `focus`，之后调整品种配置不会改变这一株已选择的时长。
- 版本 1 已种植的聚气草保留 15 分钟、月华花保留 40 分钟；下次播种采用 5 / 30 分钟。旧株按普通种植处理。
- 新物种背包缺项补零，原有种子、药材、余额和地块保留。

## 美术交付与接入

沿用既有软萌黏土 3D、翡翠 / 米白 / 暖金；每种四阶段（幼芽、幼苗、成株、可收）。成熟轮廓需明确区分：露珠、多团苔、竹节、阔叶、星兰、参根、盘藤、层叠芝、霜莲、果树。

- 规范及每阶段提示词：`focus-asset-plan.json`。将 `style`、`layout`、`background` 与指定物种的 `stages` 拼成完整出图提示词；每种单独一张 2×2 表。
- 原始文件：`docs/art-raw/crop-<id>.png`；接入文件：`assets/crop-<id>-0.webp` 至 `-3.webp`。四阶段统一缩放，最大 176×200，保留透明通道。
- 增量构建：`python scripts/build_art.py --species chenlu jingxin`，只写指定物种及清单、预览图，不重建旧美术。
- 本机素材处理环境：PowerShell 可运行 `& "$env:LOCALAPPDATA/lingcao-garden-art-venv/Scripts/python.exe" scripts/build_art.py --species chenlu jingxin`；该独立环境已安装 numpy / scipy / Pillow，不依赖系统 Python。
- 完整检查：`node scripts/check_focus_assets.mjs`，未交付资产会明确失败；功能测试允许已登记的 pending 使用现有矢量回退，不能将其视为美术验收。
- 当前已交付：十二种全部四阶段，共 48 张透明 webp。新增十种共 40 张约 249.6KB，原有两种未重建。完整 Host 素材响应约 745,829 字节，包含地砖、图标及五种背景；响应预算随十二种规模调为 800KB，并保留断言。
- 用户已明确授权切换 PPToken 并禁止使用 imagegen；本轮仅用 `pptoken-image` 管线完成十张原图生成。个别请求返回错误后只重试缺失品种；玄霜莲使用简化描述后成功，没有重生成已成功原图。
- 可复用生成命令：`python scripts/generate_focus_art.py <id...>`，调用已安装 pptoken-image skill 的配置、请求与下载函数；完整实际提示词保存在 `docs/art-prompts/focus/crop-<id>.txt`。先写下载凭据到本机忽略目录，再下载；CDN 下载失败可复用结果，不必再次生成付费。
- 预览：`docs/focus-plants-preview.png`（十二种、时间标注、四阶段缩略图）；`docs/art-contact.png`（深 / 浅底全素材检查）。`scripts/preview_focus_art.py` 校验全部 48 张尺寸、非空透明通道并重建总览。
- 导出使用同物种统一缩放、最大 176×200；新增草 webp quality 75 保持 alpha 与显示尺寸，原有草维持原图。抠图、缩放和压缩由现有 Python 管线执行。

## 验收

- 十二种均可从起始境界购买、种植、到期收获与出售；余额不足不扣费。

- 专注计时在灵雨、催熟与重载后保持结束时间；普通株可加速；开发者 GM 仍可改变时间，只供测试。
- 旧存档时长和库存保留。
- 素材检查全部 ready 且 48/48 实际文件齐全，80 项 Host / Client 测试通过；全部原图、深浅底图与十二种总览已目视检查。真实 DSH 的滚动、到期反馈与视觉验收待补。
